# 基金持仓

这是看板唯一的持仓数据源。改这张表 → 保存 → 推送，看板刷新后自动生效。

## 你要维护的列

| 列 | 说明 |
| --- | --- |
| 类别 | 分组名。看板按它汇总出「持仓概览」「仓位分布」「收益贡献」「定投节奏」，并给明细表分组加小计。**同一类别要连在一起写** |
| 基金名称 | 只用于展示 |
| 代码 | 6 位基金代码。**区间收益要靠它取净值**，留 `—` 的基金不会出现在「基金区间收益」里 |
| 定投开始/调整 | 计划文本，只用于展示，不参与计算 |
| 每日定投金额 | 想要被计入「每日定投」合计，就写成 `50 元/天` 这种格式 |
| 累计定投 | 这只基金到目前已定投进去的累计金额。只用于展示 |
| 投入本金 | 可选。累计投入的钱。只知道本金和收益、不知道市值的行，看板会自动算出市值 = 本金 + 收益 |
| 持有金额 | **当前市值**。填了就用它；留 `—` 且「投入本金」有数时会自动推算 |
| 持有收益 | 累计盈亏（金额）。填了就用它，会自动上色（正红负绿） |
| 持仓收益率 | 累计盈亏（百分比，如 `-1.00%`）。**和「持有收益」二选一**：同一行只填一个，两个都填以「持有收益」为准 |

## 看板自动算出来的列

这三列**不要写进表格**，写了也会被忽略：

- **成本** = 持有金额 − 持有收益
- **持有收益** = 持有金额 × 收益率 ÷ (1 + 收益率)——只填了「持仓收益率」没填「持有收益」的行，看板这样反推，并在明细表里用灰色虚线下划线标出
- **收益率** = 持有收益 ÷ 成本

明细表末尾的**小计 / 合计**行也由看板算出来，不用手写。

## 规则

- 看板会自动跳过上面的说明表，认表头里带「类别 / 基金名称 / 持有金额 / 持有收益 / 每日定投金额 / 投入本金 / 累计定投」的那张表。
- 列可以增删、调换顺序，看板按**表头名字**识别。
- 没有数值的格填 `—`，不要留空；金额直接写数字，别带千分位逗号。
- 顶部汇总只累加**算得出市值**的行。既没填市值、又没填本金的行会在顶部单独提示，说明它没被算进去。
- 只填「每日定投金额」、金额和收益都留 `—` 的行，会被当成**纯定投计划行**：只进「每日定投」合计，不进市值、也不会报「未计入总额」。摊不到具体某只基金上的合并定投就写成这种行。
- 收益率按「持有金额是市值」理解。

## 区间收益怎么来的

「基金区间收益」区块的数据**不在本文件里**，是 `data/returns.json`。推送前跑一次：

```bash
node tools/update-returns.mjs
```

它会逐只去天天基金拉净值，算好 1 日 / 1 周 / 1 月 / 3 月 / 6 月 / 1 年 的收益率写进那个 JSON。页面只读这个小文件。
